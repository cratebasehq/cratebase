Cratebase is pre-1.0 (`0.1.0`) with no tagged releases yet; changes are
grouped by merged pull request rather than by release tag. The 0.1.0
line (2026-09-04) covers four "value-add waves" (cross-node realtime,
incoming webhooks, OAuth2, an MCP dashboard, push notifications, schema-
as-code, SQL cron jobs, an in-dashboard SQL console/file manager, vector
search, and team membership), the full auth surface and JS hooks, and
realtime (SSE) support. The unreleased changes are a breaking release:
Cratebase is now fully its own API (`cb_*` directory names, `*.cb.js`
hooks). See the full
[CHANGELOG.md](https://github.com/cratebasehq/cratebase/blob/main/CHANGELOG.md)
for every entry and its linked PR.
