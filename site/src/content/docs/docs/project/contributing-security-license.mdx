Cratebase is MIT licensed — see
[LICENSE](https://github.com/cratebasehq/cratebase/blob/main/LICENSE).
Development workflow (`cargo test --workspace`, plus
`TEST_POSTGRES_URL=...`/`TEST_S3_ENDPOINT=...` for the Postgres/S3 parity
suites, and `bun run admin:dev` for the dashboard) is documented in the
repository's own README under **Development**. Report a security
vulnerability through GitHub's private security-advisory flow on the
[repository](https://github.com/cratebasehq/cratebase) rather than a
public issue.
