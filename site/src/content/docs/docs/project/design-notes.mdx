---
title: "Design notes"
description: "The value-add strategy behind the AI bundle and later feature waves."
---

Several later features — the AI bundle (vector search, LLM chat gateway,
MCP), teams, schema-as-code, and the plugin system — were planned in an
internal value-add strategy document before being built, scoping each
addition against "does this reuse an existing primitive or add a new
one" rather than adding surface area for its own sake. The
[`examples/docmind`](https://github.com/cratebasehq/cratebase/tree/main/examples/docmind)
worked example is the concrete proof of that scoping — it is built
entirely from primitives that already existed for other reasons.
