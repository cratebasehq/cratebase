Cratebase is a fast, self-hostable backend — dynamic collections, auth,
file storage, and realtime — in one Rust binary. Use `@cratebase/client`,
its first-party TypeScript SDK, or call the REST API directly.

**New in [v0.6.0](https://github.com/cratebasehq/cratebase/releases/tag/v0.6.0):**
background jobs from JS hooks (`$queue.enqueue` + `onQueueJob`), durable webhook
deliveries with retries and replay, multi-node-safe cron with run history, and
one-command starter kits (`bun create cratebase`). See the [changelog](/docs/project/changelog/) for the full list.
