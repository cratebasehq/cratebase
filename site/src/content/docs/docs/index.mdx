Cratebase is a fast, self-hostable backend — dynamic collections, auth,
file storage, and realtime — in one Rust binary. Use `@cratebase/client`,
its first-party TypeScript SDK, or bring the official
[`pocketbase`](https://www.npmjs.com/package/pocketbase) SDK — Cratebase
speaks PocketBase's own wire API, so it works against it unmodified.

**New in [v0.3.0](https://github.com/cratebasehq/cratebase/releases/tag/v0.3.0):**
`cratebase dev` for a one-command local loop, built-in `cratebase typegen`,
`cratebase seed`, working JS migrations, Postgres TLS and backups, a dev mail
inbox, and a round of security hardening — upgrading from 0.2.0 has a few
breaking changes. See the [changelog](/docs/project/changelog/) for the full list.
