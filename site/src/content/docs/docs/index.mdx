Cratebase is a fast, self-hostable backend — dynamic collections, auth,
file storage, and realtime — in one Rust binary. Use `@cratebase/client`,
its first-party TypeScript SDK, or bring the official
[`pocketbase`](https://www.npmjs.com/package/pocketbase) SDK — Cratebase
speaks PocketBase's own wire API, so it works against it unmodified.

**New in [v0.2.0](https://github.com/cratebasehq/cratebase/releases/tag/v0.2.0):**
a first-party TypeScript SDK ([`@cratebase/client`](https://cratebase.dev/docs/getting-started/using-js-sdk/)),
[sessions](https://cratebase.dev/docs/concepts/authentication/sessions/) with
instant server-side revocation, cookie-mode auth, and a server-driven
[OAuth2 redirect flow](https://cratebase.dev/docs/concepts/authentication/oauth2/#server-driven-redirect-flow).
See the [changelog](/docs/project/changelog/) for the full list.
