Cratebase is a fast, self-hostable backend — dynamic collections, auth,
file storage, and realtime — in one Rust binary. It speaks PocketBase's
own wire API, so the official [`pocketbase`](https://www.npmjs.com/package/pocketbase)
SDK works against it unmodified.

- New here? Start with **[Install](/docs/getting-started/install/)** and
  **[First run](/docs/getting-started/first-run/)**.
- Coming from PocketBase? Start with
  **[Migrating from PocketBase](/docs/migrating/compatibility/)**.
- Building an AI feature? Start with **[AI → Overview](/docs/ai/overview/)**.
- Looking for an endpoint? See **[Reference → REST API](/docs/reference/rest-api/)**.

Full source is at [github.com/cratebasehq/cratebase](https://github.com/cratebasehq/cratebase),
