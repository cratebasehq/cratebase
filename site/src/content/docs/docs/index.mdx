Cratebase is a fast, self-hostable backend — dynamic collections, auth,
file storage, and realtime — in one Rust binary. Use `@cratebase/client`,
its first-party TypeScript SDK, or bring the official
[`pocketbase`](https://www.npmjs.com/package/pocketbase) SDK — Cratebase
speaks PocketBase's own wire API, so it works against it unmodified.

**New in [v0.4.0](https://github.com/cratebasehq/cratebase/releases/tag/v0.4.0):**
an email platform (visual template editor, send API, triggers, magic link),
Postgres extensions and custom SQL RPC, PostGIS-accelerated nearest queries,
Apple/Microsoft/Discord/... sign-in, OIDC, TOTP 2FA, and a dashboard where
every setting is configurable. See the [changelog](/docs/project/changelog/) for the full list.
