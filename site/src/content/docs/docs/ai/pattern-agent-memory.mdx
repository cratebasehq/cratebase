title: "Pattern: agent memory"
description: "A worked walkthrough combining vector search, MCP, cron expiry, and realtime."
---

The [`examples/memories`](https://github.com/cratebasehq/cratebase/tree/main/examples/memories)
walkthrough builds "an agent remembers things across sessions" from
existing primitives with zero new server code: a `memories` collection
with a `vector` field for semantic retrieval, owner-scoped rules so an
agent's memories are private to its own identity, automatic MCP tool
exposure for reading/writing memories, a cron job that expires rows past
an optional `expiresAt`, and a realtime subscription for a live
"thinking" feed. Nothing here is memory-specific infrastructure — it's
five existing features composed.
