---
title: "In-dashboard API docs"
description: "The per-collection API tab showing request shapes for the schema you defined."
---

Every collection's detail view has an **API** tab rendering the request/
response shapes (list, view, create, update, delete, and any auth
endpoints if it's an auth collection) for that collection's actual
current schema and rules — no separate spec to keep in sync by hand
while you're iterating on a collection's fields.
