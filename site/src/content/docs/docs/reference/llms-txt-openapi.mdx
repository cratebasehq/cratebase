[`llms.txt`](https://github.com/cratebasehq/cratebase/blob/main/llms.txt)
at the repository root is a quick orientation document written for both
humans and LLMs — a good first thing to paste into an agent's context
before asking it to write code against Cratebase.
[`openapi.yaml`](https://github.com/cratebasehq/cratebase/blob/main/openapi.yaml)
is the machine-readable API spec the [REST API reference](/docs/reference/rest-api/)
page will be generated from.
