### `GET /collections/{name}/tool-schema` — superuser only

Returns the same JSON-Schema/OpenAI-function-calling-shaped conversion
`POST /mcp`'s `tools/list` uses internally to build its
`create_<collection>` tool definition, for a caller that wants the shape
without speaking MCP at all:

```json
{
  "name": "posts",
  "description": "The 'posts' base collection (3 fields).",
  "parameters": { "type": "object", "properties": { "title": {"type": "string"}, "body": {"type": "string"}, "tags": {"type": "array"} }, "required": ["title"] }
}
```
