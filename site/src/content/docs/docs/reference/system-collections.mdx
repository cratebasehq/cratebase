---
title: "System collections"
description: "Names, fixed ids, and rules for every built-in collection."
---

`_superusers`, `_mfas`, `_otps`, `_externalAuths`, `_authOrigins`,
`_teams`, `_team_members`, `_cron_jobs`, `_webhooks`, `_audit_log`,
`_push_subscriptions`, and the default `users` auth collection all ship
with fixed, deterministic ids shared with PocketBase's own equivalents
where one exists — see [Collections](/docs/concepts/collections/) for
the id-derivation formula that makes this consistent.
