---
title: "Self-hosted web analytics"
description: "A <2KB cookie-free beacon posting pageviews into an ordinary collection."
---

The whole feature is a public collection plus a small script: import
`web/beacon/analytics-collection.json` (a public `createRule`, everything
else superuser-only), drop `web/beacon/beacon.js` (under 2KB, zero
dependencies) in a `<script>` tag pointed at your instance, and the
dashboard's **Settings → Analytics** page reads the same collection back
through ordinary list/filter/sort queries — total pageviews, unique
paths, top referrers, a daily chart. No cookie, no `localStorage`,
nothing that could be replayed as a persistent visitor id. Known
limitation: no unique-visitor counting — what ships is an honest count of
what the beacon actually sends (raw pageviews, distinct paths,
referrers), not a privacy-safe unique-visitor estimate.
