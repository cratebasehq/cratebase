description: "Dashboard-minted keys as ordinary identities, for agents and CI."

---

Superusers can mint API keys from the dashboard's **API keys** page.
An API key is just another identity — the same rule-gated access any
other authenticated record gets, nothing bespoke — which makes it a
natural credential for a CI job, a service, or an [MCP-connected
agent](/docs/ai/mcp-server/).
